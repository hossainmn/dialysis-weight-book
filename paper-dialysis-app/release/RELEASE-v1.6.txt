SECURITY (why it is safe)
- Offline only. Merged release manifest requests ZERO dangerous permissions.
  `aapt dump badging` shows only com.example.dializpaper.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION (androidx internal).
  No INTERNET, no storage, no location. Data stays in private WebView localStorage.
- android:allowBackup=false, android:usesCleartextTraffic=false (AndroidManifest.xml:5-6).
- FileProvider exported=false, grantUriPermissions=true. MainActivity exported=true (launcher requirement only).
- Import path hardened: MainActivity.java caps at 5MB, requires JSON starting with '{' + dialysis markers,
  uses JSONObject.quote before bridge.eval, closes streams, expires pending after 12s.
- www/index.html: esc() on all notes/numbers/dates, cleanId strips to [a-zA-Z0-9_-] (32 chars),
  normalizeEntry re-parses weights, 5MB cap, JSON.parse in try/catch, user must tap confirm in receiveModal.
  No eval, no document.write, no remote scripts, fonts local.
- `npm audit` shows 1 high + 1 critical in tar via @capacitor/cli (BUILD TOOL only, not shipped in APK/AAB).
  Fix would force Capacitor 8 (breaking) - intentionally not applied. No runtime impact.
- Honest limit: no app is "unhackable". Remaining surface is a malicious .dializ backup file,
  which cannot auto-run: it is validated, preview-counted, and needs your tap to merge. Keep phone OS updated.
